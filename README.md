## Engineering principles

- Prefer automation that is repeatable, documented, and reviewable.
- Use least privilege and secure defaults.
- Start with read-only inventory and dry-run modes before making changes.
- Test in isolated environments before production use.
- Keep credentials, customer data, and environment-specific configuration out of source control.
