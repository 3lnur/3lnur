## Engineering principles

- Automate repeatable work; keep human review for risky changes.
- Prefer least privilege and secure defaults.
- Start with inventory and read-only checks before making changes.
- Test in isolated environments before production.
- Document assumptions, dependencies, rollback steps and expected results.
- Never commit credentials, customer data or internal configuration.
